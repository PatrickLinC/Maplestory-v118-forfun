# PoE 風格附魔系統 — 玩法介紹

本服的招牌特色:一套借鏡《流亡黯道》(Path of Exile)詞綴思維、重做在楓之谷裝備上的**附魔石／潛能系統**。

> 這份文件只介紹**玩法**。實作原始碼(引擎、數值表、機率、整合掛鉤)屬本服獨門設計,**不公開**;有興趣交流實作歡迎私訊。

---

## 核心概念

- 每件裝備最多有 **4 排**詞綴,每排是一條隨機屬性(例:攻擊力 +5、傷害 +8%)。
- 用不同的**附魔石**去賦予、重洗、增加排數,或做高風險的「污染」強化。
- 每種詞綴有**三段強度**(低／中／高),抽到的排數與強度都隨機——這就是 PoE 式的「刷詞綴」樂趣。
- 較強的詞綴(如攻擊力、傷害%、Boss傷害)只會在較後面的排數出現,越滿排越有機會出現強詞。

---

## 詞綴種類(共 24 種)

| 類別 | 詞綴 |
|---|---|
| 基礎屬性 | 力量%、敏捷%、智力%、幸運%、最大HP%、最大MP% |
| 防禦 | 物理/魔法防禦 |
| 命中機動 | 命中、迴避、速度、跳躍 |
| 攻擊 | 攻擊力、魔法攻擊力 |
| 進階戰鬥 | 傷害%、爆擊機率、爆擊傷害、無視防禦、Boss 傷害、技能等級 |
| 抗性/特殊 | 暈眩抗性、魅惑抗性、黑暗抗性、消除技能抗性、無效解除 |

- **平值型**(攻擊力/主屬性/防禦…):直接寫進裝備能力值,tooltip 與螢幕跳字都看得到。
- **乘算/特殊型**(傷害%/爆擊/Boss傷害/無視防禦/抗性/無效解除…):由伺服器戰鬥結算套用,實際有效;因 v118 客戶端限制,部分不會反映在螢幕跳字上。

## 十種附魔石

| 附魔石 | 效果 | 稀有度 |
|---|---|---|
| 基礎附魔石 | 賦予 2 排詞綴 | 常見 |
| 高階附魔石 | 重洗(重抽)目前排數的詞綴 | 常見 |
| 神聖附魔石 | 重洗「所有排」的數值 | 中 |
| 祝福附魔石 | 重洗「其中一排」的數值 | 中 |
| 淬鍊附魔石 | 洗詞綴 + 機率加一排(失敗也會變動) | 較稀有 |
| 富豪附魔石 | 機率加一排(只有成功才變動) | 較稀有 |
| 神話附魔石 | 直接補滿 4 排 | 稀有 |
| 瓦爾附魔石 | 機率洗成 3／4 排,成功則裝備污染 | 稀有 |
| 瓦爾崇高附魔石 | 保底 2 排 + 第 3 排,並污染 | 極稀有 |
| 瓦爾神話附魔石 | 保底 3 排 + 第 4 排,並污染 | 極稀有 |

---

## 污染(高風險高回報)

- 瓦爾系附魔石在給你更多排數的同時,會讓裝備進入**污染**狀態。
- **污染後無法再附魔**——所以是「一翻兩瞪眼」:賭一把換到滿排強詞,或就此定格。
- 污染裝備在名稱前會顯示「**已汙染的○○**」,一眼可辨。

---

## 怎麼取得附魔石

1. **打怪掉落**:所有怪物都可能掉,越稀有的石頭掉率越低(基礎石很常見,神話/瓦爾系極罕見)。
2. **NPC 購買**:向附魔師 NPC 用楓幣購買(基礎款便宜,高階款昂貴)。
3. **Boss 獎勵**:Boss 有機率掉「**附魔石寶箱**」(開啟隨機獲得一顆,越稀有機率越低),且 Boss 對各種石頭另有掉率加成。

v118 客戶端原生不會畫潛能行。本服透過**客戶端 tooltip hook**(見 [`client-hook/`](../client-hook/) 的通用顯示技術)把附魔詞綴畫在裝備素質下方、並依污染狀態改名字前綴,讓玩家一如原生潛能般直接在裝備上看到附魔結果。
